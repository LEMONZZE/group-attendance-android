# Посещаемость

Нативный офлайн-журнал посещаемости для старосты группы. Приложение написано на Java с Android SDK без сторонних библиотек и работает на Android 8.0 и новее.

## Возможности

- Журнал по дням: все присутствуют по умолчанию, а нажатие на фамилию или галочку меняет отметку и сразу обновляет счётчики.
- Список группы: добавление, редактирование, удаление и вставка нескольких имён разом. Старые отчёты сохраняют состав группы на выбранную дату.
- Отчёт в буфер обмена: например, «Отсутствуют 3 чел.: Аксёнов, Анейчик, Блюдник.»
- Данные сохраняются после каждого изменения. Приложение не требует интернет-доступа или регистрации.

## Как пользоваться

1. Перенеси APK на телефон, открой его через «Мои файлы» и установи. Если Android попросит, разреши установку приложений для «Моих файлов». После установки это разрешение можно отключить.
2. Во вкладке «Список группы» нажми «Добавить человека» или «Вставить список». Формат: `Аксёнов И.И.`, по одному человеку на строку.
3. Во вкладке «Посещаемость» нажимай на фамилию или квадратик, чтобы отметить отсутствие. Для отчёта нажми «Скопировать» и вставь сообщение в чат.

Если для прошлой даты списка ещё нет, можно взять текущий состав только для этого дня. Данные хранятся на телефоне и удаляются при удалении приложения или очистке его данных.

## Как устроено

- `MainActivity` — нативный интерфейс, календарь, копирование отчёта и запись журнала через `AtomicFile`.
- `AttendanceBook` — модель без зависимостей от Android: версии списка по датам и отдельное хранение отметок для каждого дня.
- `AttendanceBookTest` — проверки истории, изменений состава, формата отчётов и чтения сохранённых данных.

## Сборка

Нужны JDK 17+ и Android SDK (Platform 35, Build-Tools 35.0.1), а также `zip` и `openssl`:

```sh
export JAVA_HOME=/path/to/jdk
export ANDROID_SDK_ROOT=/path/to/android/sdk
bash test.sh
bash build.sh
```

Готовый `Attendance.apk` появится в корне проекта. При первой сборке создаётся локальный ключ подписи в скрытой папке `.signing`, которая не входит в репозиторий. Храни её в безопасности: тот же ключ нужен для обновления установленного приложения без удаления данных. Для новых версий увеличивай `android:versionCode` в манифесте.
